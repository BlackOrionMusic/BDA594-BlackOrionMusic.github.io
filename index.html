Selected Dataset

Dataset: Titanic Passenger Dataset (titanic.csv)

Source: Titanic Dataset on GitHub

This dataset contains detailed information about passengers aboard the RMS Titanic, including age, gender, ticket class, fare, cabin, and whether each passenger survived. It is widely used in introductory data science courses because it is clean, easy to analyze, and demonstrates how demographic and socioeconomic factors can influence survival outcomes. The dataset is ideal for practicing data cleaning, exploratory data analysis, and basic machine learning classification techniques.
